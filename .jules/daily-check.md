# Daily Check Automation

*   **Focus/Mission:** Encourage daily activity.
*   **Daily Process & Checks:**
    1. Triggers daily at 12:00 AM.
    2. Scans workspace tasks. If a user hasn't created a task AND hasn't moved a task to "Done" today, email them.
*   **Scope:** Specifically targets 2 users in the system.
*   **Requirement:** Mandatory. Implemented in the core `scheduled` function.
