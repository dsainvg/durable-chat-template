# Sync Duo

A focused project workspace built for teams of two.

## Features
- Real-time collaboration via WebSockets
- Custom spaces and dynamic task fields
- Multiple views: Kanban, List, Table, Calendar, Gantt
- Automated email notifications and workflows
- Robust API access

## Getting Started

### Prerequisites
- Node.js
- pnpm

### Setup
1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Setup Local Environment:
   ```bash
   pnpm run build
   ```

3. Run Local Server:
   ```bash
   pnpm dev
   ```

### API Access
Please refer to `docs/api.md` for full documentation on how to interact programmatically with Sync Duo via API keys.
